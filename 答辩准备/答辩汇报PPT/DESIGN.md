# 视觉设计（学术风 · 答辩汇报）

## 硬约束

- 画布 1280×720，安全边距左右 40；A 区页眉固定 A3（深蓝顶条）；D 区页脚含页码 NN/13。
- 配色只取学术风四主色 + 文本三色 + 线框两色：
  - 主蓝 `#1E4FA8`（顶条、编号、强调）
  - 藏蓝 `#0E3F8C`（深底、章节条）
  - 浅蓝 `#E8EFF8` / `#F0F5FC`（卡底、表头）
  - 中蓝 `#3D7BD9`（描边、次序列）
  - 警示红 `#D9534F`（异常/风险，单页 ≤3%）
  - 数据黄 `#FFC107`（核心金句，单页 ≤3%）
  - 文本 `#1A2230` / `#4A5568` / `#8B97A8`；线框 `#D6DCE5` / `#E5E7EB`；背景 `#FFFFFF` / `#F7F9FC`
- 字体 ≤2 套：思源黑（正文 / 标题 / KPI）。
- 字号下限：正文 ≥22px，卡内标题 ≥24px，标题 32–40px Bold 深蓝，页码 14–16px。

## 版式规则

- 内容页 C 区（A3 模式 y 80–660）必须铺满 1200×560 以上；卡片正文 22–26px、行高 1.55。
- 每页 ≥1 个视觉锚点（≥44px 元素 或 ≥40% B 区面积的图）。
- 封面 / 目录 / 致谢可省略页眉页脚，其余页一律 A3 顶条 + 右下页码。
- 配图全部来自 `assets/`（本地真实实验结果图，非生图），单页最多 1 张大图（宽 ≤760）+ 文字卡。
