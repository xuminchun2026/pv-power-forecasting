## 第一步：Overleaf 出 PDF（30 分钟）

1. 手机开热点 → Mac 连热点
2. 打开 https://www.overleaf.com → 右上角登录（如果你还没账号，先注册一次就够，**别反复点注册页**，会被 GitHub/Overleaf 限流）
3. 进你已有那个项目 → 左下角**齿轮 ⚙️ → Compiler** → 确认是 **XeLaTeX**
4. 回**项目列表页** → 点绿色 **`New project` 旁边的小三角 ▾ → 第三行 `Existing project (.zip)`** → 选 `overleaf_upload.zip`
   > ⚠️ 新版界面**没有** `Menu → Upload Project` 这条了（今天下午实测确认），照老教程找会白找半天。
   > `File ▾` 里只有 `Upload file`（单文件，覆盖不了整份项目）。
5. 点 **Recompile**，等 1~2 分钟；底部日志必须是 **0 errors**
6. 出 PDF 后：**点 `Recompile` 右边那个 ⭳ 图标下载** → 存到 `~/Desktop/电气club作业/光伏功率预测_徐敏纯_3120260807425.pdf`
   > 判有没有覆盖成功：`main.tex` 第 4 行应为 `\documentclass[11pt,a4paper]{ctexart}`（旧版是 `lipt`）。
   > 若弹窗里选成了 New project，会多出一个标题带 `(1)` 的副本，副本编译器退回 pdflatex 会报 `fandol` 字体错 → 在副本里 ⚙ 改回 XeLaTeX 即可。

> 如果还是报 "PDF Rendering Error" 但左边写着 Errors 0 —— 那是网页在下载 PDF 时被校园网拦了，
> 不是代码错。**刷新两次 / 换热点 / 直接下载 output.pdf** 就能出来。

# 第三节：口语替换文案（你读一遍，挑几句改）

> 规则：**不要抄**，看完意思，用自己的话说。
> 下面示范的是「结论第 3 条」和「摘要首句」，你照这个程度自己动手改别的段落。

### 示范 1｜结论第 3 条（原文 → 口语版）

**原文（偏书面）**
> 模型增益高度依赖天气动态：辐射突变 30~60 W/m² 时降幅达 72.5%，而辐射平稳（突变 <10 W/m²）时段 Persistence 反而更好。这说明 Persistence 是平稳天气下的天然强基线，不应被无条件忽略，实际使用时宜按辐射突变强度切换预测策略。

**口语版（你自己改一版出来，别照抄这句）**
> 我的第三个发现是最反直觉的：我不是说模型处处都好。辐射变化大的时候（突变 30 到 60 之间）模型能降 72.5% 的误差，效果最好；但到了辐射特别平的时段（突变小于 10），Persistence 反而比模型好 88% —— 因为辐射本来就不动，上一刻的功率就等于现在的功率，模型去拟合反而添了波动。所以我的建议是：别无脑上模型，按辐射变没变来切换策略。

### 示范 2｜摘要首句（原文 → 口语版）

**原文**
> 光伏短时出力预测是新能源并网调度的基础。

**口语版（供参考，你自己写一句更像你说话的）**
> 光伏最大的麻烦就是「说停就停」，天一黑出力直接归零，电网调度得提前知道它等会儿发多少电，所以得预测。
